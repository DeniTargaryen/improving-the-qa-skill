## Что выкинули как бесполезное (явно, не молча)

1. **`unittest.mock` как «приоритет №1 месяца»** — понижен статус, оставлен как короткий обязательный пункт (уже закрыт), не центральная тема. Причина: для профиля с реальным Mountebank-опытом это не топовый по ценности навык — топовый навык уже есть, трек должен его **защищать словами**, не переучивать инструмент низшего уровня.
2. **2.2-Б/В (mock вместо week0-теста, requests-mock)** — скипнуты, тот же паттерн без нового навыка.
3. **Отдельный блок «ручная JSON-схема» (`validate_post_schema` с нуля)** — вырезан как отдельная задача. Рынок не подтвердил запрос «напиши валидатор схемы руками» как отдельный навык; библиотечное использование `pydantic`/`jsonschema` — не тема кодинга на собесе для этого уровня.
4. **`JsonPlaceholderApi(BaseApi)` с захардкоженным URL как паттерн API-клиента** (блок 1.1, для протокола) — не повторяется в новых блоках недели 2–4; это было признано ошибкой ещё в ревью 10.08, подтверждаю решение не защищать этот паттерн дальше.
5. **`PostsApi`/`UsersApi`-классы поверх `BaseApi`, Page Object/UI-слой, полноценный CI/CD, `AbstractApi`/интерфейсы «на будущее», async/await, DB/SQLAlchemy** — весь список из старого плана (`docs/superpowers/plans/2026-08-05-post-week0-aqa-plan.md`, раздел 4) остаётся в силе, рынок 2025–2026 не добавил новых причин это открывать для этой цели (ASAP AQA Python middle, не платформенный/senior архитектурный трек).
