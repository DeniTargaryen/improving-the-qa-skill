**Статус: опциональный.** Открывается только если недели 2–3 закрыты с запасом времени. Если время поджимает — пропусти с устной формулировкой на собесе «пользуюсь Allure на текущей работе (шаги, аттачи, окружение), руками с нуля не собирал отчёт — но с инструментом на ежедневной основе»: это **честно и достаточно**, Allure у тебя и так есть в резюме как реальный опыт с текущей работы, этот блок не про «научиться Allure», а про «не растерять то, что уже умеешь, когда покажут твой же тест».

**Зачем блок, если делаешь:** не проседать в 2 минуты live-демо «покажи код с Allure», не строить вокруг него архитектуру.

```bash
python -m pytest 03_api_framework -v --alluredir=allure-results
```

(команда генерации HTML-отчёта — `allure serve allure-results`, если `allure` CLI установлен локально; если нет — достаточно, что тесты пишут `allure-results`, сам просмотр отчёта не обязателен для этого блока)

## Какая проблема

На собесе (или демо в компании) обычный вопрос: «покажи тест, как у тебя оформлена отчётность». Голый `assert` в теле теста ничего не объясняет по шагам — Allure превращает тест в читаемый сценарий.

## Фича

В **двух-трёх** своих тестах (не переписывай логику, просто добавь разметку):

1. `@allure.step("текст шага")` — оберни 2–3 логических шага внутри теста (например: «создать пост» / «проверить статус» / «удалить пост»).
2. `allure.attach(...)` — на одном тесте приложи тело ответа (JSON) при падении или просто для примера (`allure.attach(str(response), name="response body", attachment_type=allure.attachment_type.JSON)`).

## Кто кого вызывает

`import allure` в начале файла теста → внутри теста оборачиваешь логические кусочки в `with allure.step("..."):` (или через декоратор `@allure.step` на маленькой вспомогательной функции) → при прогоне с `--alluredir=...` pytest-плагин `allure-pytest` сам собирает эти шаги в отчёт, твоя тестовая логика (`assert`) не меняется.

### Что возвращает

Ничего нового по типам — `allure.step`/`allure.attach` не меняют поведение теста, только обогащают отчёт. Критерий сдачи — тесты всё ещё зелёные + в файле реально есть `@allure.step`/`with allure.step` на 2–3 шагах и один `allure.attach`.
