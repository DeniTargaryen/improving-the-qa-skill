# Drill 02 — Частоты и самый частый

## 1. `count_frequencies(items: list) -> dict`

**Что возвращает:** словарь `dict`, где  
- **ключ** = элемент из списка  
- **значение** = сколько раз этот элемент встретился (целое `int`)

**Не возвращает:** список, число, `None`.

| Вход `items` | Что должна вернуть функция |
|--------------|----------------------------|
| `[1, 3, 3, 2]` | `{1: 1, 3: 2, 2: 1}` |
| `[]` | `{}` (пустой dict) |
| `["a", "b", "a"]` | `{"a": 2, "b": 1}` |

---

## 2. `most_frequent(items: list)`

**Что возвращает при нормальном входе:** **один элемент** из списка — тот, что встречается чаще всех.  
Тип как у элементов списка (число или строка) — **не** частота, **не** словарь, **не** индекс.

**Что возвращает / делает при пустом списке:** ничего не возвращает успешно — должна **`raise ValueError`**.

**Ничья** (несколько элементов с одинаковой макс. частотой): верни тот элемент, который **раньше всех** впервые появился в `items`.

| Вход `items` | Что должна вернуть / сделать функция |
|--------------|--------------------------------------|
| `[1, 3, 3, 2, 1, 3]` | `3` (элемент, не частота `3` как счётчик — здесь совпало числом, но смысл: **элемент-победитель**) |
| `[1, 2, 1, 2]` | `1` (оба с частотой 2 → победил кто раньше) |
| `[42]` | `42` |
| `[]` | исключение `ValueError` |

Важно: возвращаешь **ключ-победитель** (элемент), а не число «сколько раз он встретился».
