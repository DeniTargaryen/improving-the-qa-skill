## Зачем

Базовый Python без автопилота: `dict`, циклы, строки. Это же часто дают на разминке лайвкодинга.

## Что сделать

В файле `solution.py` реализуй **три функции** (сигнатуры уже есть):

### 1. `count_frequencies(items: list) -> dict`

Словарь «элемент → сколько раз встретился».

Пример: `[1, 3, 3, 2]` → `{1: 1, 3: 2, 2: 1}`

### 2. `find_duplicates(items: list) -> list`

Список элементов, которые встречаются **больше одного раза**.  
Порядок — **по возрастанию** (для чисел/строк обычная сортировка).  
Без дублей в ответе.

Пример: `[1, 2, 3, 2, 1, 7]` → `[1, 2]`

### 3. `most_frequent(items: list)`

Элемент с максимальной частотой.  
Если таких несколько — верни тот, который **раньше встречается** в исходном списке.

Пример: `[1, 3, 3, 2, 1, 3]` → `3`  
Пример: `[1, 2, 1, 2]` → `1` (ничья по частоте, 1 был раньше)

### 4. `reverse_string(s: str) -> str`

Строка задом наперёд.

Пример: `"Yandex"` → `"xednaY"`

Любой корректный способ ок. На собесе могут попросить ещё вариант через цикл — имей в виду.

## Пустой список

- `count_frequencies([])` → `{}`
- `find_duplicates([])` → `[]`
- `most_frequent([])` → должно бросить `ValueError`
